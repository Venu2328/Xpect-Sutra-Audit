# Xpect | Sutra AI Auditor 🛡️

**Xpect** is an AI-driven compliance prototype designed to align Indian banking operations with the **RBI 2025 FREE-AI Framework**. It specifically audits automated lending models against the **7 Sutras** of ethical AI.

### 🚀 Key Features
* **Sutra Health Index:** Real-time scoring based on Fairness, Explainability, and Trust.
* **Glass-box Visualization:** Deciphering "Black Box" AI decisions for transparency.
* **Compliance Automation:** Instant auditing of synthetic banking datasets (CSV).

### 🛠️ Technical Stack
* **Frontend:** HTML5 / CSS3 (Designed in Canva)
* **Logic:** Vanilla JavaScript / Python (Synthetic Data Processing)
* **Framework:** RBI FREE-AI 2025 Compliance Standards

### 📝 Project Vision
Developed to support the transition toward 'Understandable by Design' AI in the Indian FinTech ecosystem, ensuring that innovation never comes at the cost of ethics.
